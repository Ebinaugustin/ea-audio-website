A smaller panel.

The latest preview brings a compiled universal Mac installer and the improvements below. The Windows ReaPack package is still v2.2.4.

01 / SENDS

Copy Send 1–10

Ten separate commands copy each send slot’s volume, pan and mute automation. Paste matches an existing bus first, then the send slot. It never creates missing sends; unmatched parameters are reported.

02 / PREVIEW

See it. Follow it.

The whole Preview button blinks green while active; the separate dot is gone. Preview follows across all tracks and Master. Turning it off sets them to Read and removes the global override. Ctrl/Cmd-click retains Preview A/B suspension.

03 / DOCKING

Reveal as you resize

Controls keep their chosen size while the Docker divider reveals more rows or columns. Thin top/bottom docks form a row; narrow side docks form a column. Overflow scrolls instead of shrinking the whole toolbar.

04 / SECTIONS

Keep what you use

Right-click → Show sections lets you show or hide Suspend, Write Enable, Manual Write, Write on Stop and Copy/Paste. Section choices are saved; hiding a section does not change its automation state.

05 / LEGIBILITY

Clearer small controls

Small text and vector icons render at their final size on the pixel grid. The panel reads REAPER 7’s Inter/Inter Medium fonts when present, with system-font fallbacks. Exact 50–200% presets remain available.

06 / SHORTCUTS

104 actions

Separate send-copy and section-visibility actions join the existing commands. Assign your own keys in REAPER’s Main Actions list. The panel also preserves your “Automatically add envelopes when tweaking parameters in automation write modes” preference.

These are v2.2.15 preview features. Automated checks passed; live Mac REAPER testing and the reported track volume/pan write issues remain open.

WHY I MADE IT

A familiar place
to keep working.

Switching from Pro Tools, I wanted a compact automation window that felt familiar in a post session. REAPER’s scripting and extension capabilities made it possible to build one around its own automation system.

THE AUTOMATION WORKFLOW

Preview. Capture.
Write.

Keep the controls you reach for together, then put the actions under your own keyboard shortcuts.

01 / ENABLE

Choose your parameters

Write Enable gates plug-in parameters, track volume/pan/mute and send volume/pan/mute. PAN includes ReaSurround and ReaSurroundPan.

02 / HOLD

Preview & Capture

Hold values in Preview and suspend/resume it for A/B comparison. The whole Preview button blinks green when active. Capture scoped values, or Ctrl/Cmd-click Capture for selected tracks with a blinking indicator.

03 / COMMIT

Write to your range

Five Manual Write ranges and five Write on Stop modes. A successful Manual Write exits Preview. Writing the full session without a time selection asks for confirmation.

04 / REUSE

Copy. Paste. Fill.

Copy All, Copy Pan, or an individual send slot from 1–10. Paste at cursor, stretch to selection, or repeat/fill to selection. Ordinary envelope points are the default; automation items are optional.

05 / MATCH

Keep your routing

Paste automation across tracks using parameter matching. Sends use existing routing: match the bus first, then the send slot. Missing parameters are reported.

06 / CONTROL

Join, match & suspend

Auto Join, Auto Match, track scope and automation modes stay in reach. Suspend bypasses existing envelopes and restores their previous activation when released.

CURRENT TESTING STATUS

Known issues.
Useful feedback.

This is a tool still being tested in live REAPER sessions. Reproducible reports help identify where the host behaves differently.

Track volume and ordinary track pan Manual Write have reported cases of cursor dips/two points instead of the selected-range write, along with unexpected envelope-lane visibility. Recent hotfixes address these paths, but live confirmation remains pending.

If you encounter a problem, include the running version, affected parameter, Preview state, track scope and whether a time selection was present. The engine can write ManualWrite-diagnostics.txt beside engine.lua when verification fails.

Windows native checks and the 104-scenario Lua model suite (1,393 assertions) passed. The Mac universal build, Intel/Apple Silicon model checks and disposable-Mac install/upgrade checks passed. These checks do not verify live REAPER automation or Mac docking/scaling; live platform feedback is still needed. Linux compilation remains pending.
